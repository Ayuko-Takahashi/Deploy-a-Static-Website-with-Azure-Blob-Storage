# Deploy a Static Website with Azure Blob Storage

This repository demonstrates how to host a static website using Azure Blob Storage in Microsoft Azure. The project uses Azure Storage Accounts to publish web content and configure a custom error page without requiring a traditional web server.

## 🚀 Project Overview

The goal of this project was to deploy and test a static website using Azure Blob Storage. The lab covers the creation of storage resources, enabling static website hosting, uploading website files, and configuring a custom 404 error page for improved user experience.

## 🧩 Key Activities

- Created a Resource Group to organize Azure resources
- Created an Azure Storage Account
- Enabled the Static Website feature within Blob Storage
- Uploaded a custom `index.html` page to the `$web` container
- Created and uploaded a custom `404error.html` page
- Accessed the website through the generated endpoint URL
- Tested website functionality and custom error handling
